# Kairos, le suivi de colis de la justice

Projet du hackathon Droit × Microsoft (octobre 2026).

Kairos est une brique d'intelligence artificielle branchée sur Cassiopée. Elle s'assure qu'une décision de justice arrive à chaque personne qu'elle concerne, au bon moment, et le prouve : envoyé, distribué, consulté. Le greffe valide chaque envoi, l'IA ne décide rien.

## Contenu

| Fichier | Rôle |
|---|---|
| `Kairos.pptx` | Présentation PowerPoint (13 diapositives, notes de l'orateur, vidéo de démo incorporée) |
| `presentation.html` | La même présentation en HTML, à ouvrir dans un navigateur (touches : flèches, N notes, S sommaire, F plein écran) |
| `demo/kairos.html` | Prototype cliquable, fonctionne hors ligne |
| `Kairos-dossier-redige.pdf` | Dossier rédigé et pitch |
| `SKILL.md` | Guide de design du front |
| `presentation-chronos-ancienne.html`, `_version_circulation/` | Archives des versions précédentes (nom de travail : Chronos) |

## Remarques

- Toutes les données de la démonstration sont fictives.
- Les chiffres de l'Inspection générale de la justice (rapport n° 073-25, décembre 2025) sont déclaratifs, voir les sources dans le dossier.
- Le prototype montre encore la libération de M. R. et non la décision d'appel du pitch.
