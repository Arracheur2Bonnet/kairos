# Glossaire

Les noms de logiciels du prototype (APPI, WinCI TGI, WinEURS, PPN, RPVA) servent d’exemples de sources ; aucun n’est branché.

| Terme | Sens |
|---|---|
| Cassiopée | Chaîne applicative des tribunaux judiciaires pour la procédure pénale et les enfants ; créée par l’article 48-1 et les articles R. 15-33-66-4 et suivants du CPP ; finalités : délai de traitement et information des victimes (CNIL, délibération n° 2009-170) |
| GENESIS | Logiciel de gestion des personnes écrouées de l’administration pénitentiaire ; source des dates de libération dans le prototype |
| APPI | Logiciel de l’application des peines (juge de l’application des peines, SPIP) |
| WinCI TGI, WinEURS | Logiciels civil (juge aux affaires familiales) et de l’assistance éducative (juge des enfants), tels qu’utilisés comme exemples dans le prototype |
| PPN | Sigle utilisé dans le prototype pour les procédures de la police nationale |
| RPVA | Réseau privé virtuel des avocats |
| SISPoPP | Dossier commun créé pour les affaires de violences intrafamiliales ; peu utilisé parce qu’il faut tout y ressaisir (IGJ) |
| IGJ | Inspection générale de la justice |
| TJ | Tribunal judiciaire |
| CA | Cour d’appel |
| OP | Ordonnance de protection (délivrée par le juge aux affaires familiales) |
| JAF, JAP, JLD, JE | Juge aux affaires familiales ; juge de l’application des peines ; juge des libertés et de la détention ; juge des enfants |
| SPIP | Service pénitentiaire d’insertion et de probation |
| AEMO | Action éducative en milieu ouvert |
| Greffe, greffier | Service et agent qui assistent le juge et tiennent les dossiers ; c’est eux qui valident chaque envoi dans Kairos |
| Parquet | Ministère public |
| PV | Procès-verbal |
| Caducité | Sanction qui fait perdre son effet à un acte de procédure, par exemple un appel dont une formalité ou un délai n’a pas été respecté |
| Judilibre | Open data des décisions de justice de la Cour de cassation et des juridictions de l’ordre judiciaire |
| FIJAIS | Fichier judiciaire national automatisé des auteurs d’infractions sexuelles ou violentes (articles 706-53-1 et suivants du CPP) |
| FPR | Fichier des personnes recherchées (article 230-19 du CPP) |
| COMEDEC | Communication électronique des données de l’état civil |
| DGFiP, Datapass | Direction générale des finances publiques ; guichet d’habilitation d’accès aux API publiques |
| AIPD | Analyse d’impact relative à la protection des données |
| RGS | Référentiel général de sécurité |
| SecNumCloud | Qualification de l’ANSSI pour les clouds de confiance |
| HSM | Module matériel de sécurité, qui garde les clés de chiffrement |
| FIDO2 | Norme de clés de sécurité physiques pour l’authentification forte |
| DSFR | Système de design de l’État, réservé aux sites publics ; non utilisé ici |
| Brique | Composant qui s’ajoute à un logiciel existant sans le remplacer |
| Vigie, Chronos, Kairos | Noms successifs du projet : Vigie procédurale (début du 15 octobre), Chronos (14 h 26), Kairos (soir du 15 octobre). « Kairos » signifie en grec le bon moment. « Syndeo » est un nom de travail de l’auteur d’une note collée, jamais le nôtre |
